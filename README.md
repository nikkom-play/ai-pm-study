# AI PM — подготовка

Учебник, вопросы и автономная читалка для Safari.

При первом открытии дождись статуса «Можно читать без интернета». Затем учебник доступен без сети. Ответы и место чтения сохраняются в браузере на устройстве. Кнопка «Скопировать всё для ChatGPT» переносит вопросы и ответы в буфер обмена; отправка в чат выполняется вручную. При возвращении чтение остаётся на паузе.

В этом репозитории нет ответов пользователя, исходных чатов, PDF-книг или эталонов оценивания. Удаление данных сайта удаляет локальный прогресс; резервную копию можно сохранить кнопкой в читалке.
