# Роль продакта и работа с командой

https://nikkom-play.github.io/ai-pm-study/

Восемь разделов о задачах продакта, взаимодействии с командой и внедрении внутренних продуктов. Примерно 17–21 минута автоматического чтения при 250–300 словах в минуту, без ручных пауз.

Управление: Читать / Пауза, по одному фрагменту назад и вперёд, полный абзац с выбором слова, скорость, шрифт, светлая/тёмная/OLED тема. На компьютере: пробел, ← →, ↑ ↓, P и F. Место и настройки сохраняются на устройстве, чтение останавливается при переключении приложения. После первой успешной загрузки доступна офлайн-копия.

В этой публикации нет личных ответов, оценок, исходных чатов, книг, PDF, частных сведений работодателя и банков вопросов. Техническая теория, экономика и материалы интервью распространяются отдельно. Учебные ситуации придуманы для объяснения; ссылки на основу находятся в меню.

Редакция 22 октября 2026 полностью меняет структуру старой книги. Новая редакция начинается с первого раздела, настройки сохраняются, старое место чтения архивируется на устройстве. Обновление устанавливается кнопкой «Сохранить место и обновить».
