# AI PM — подготовка

Автономная читалка учебника AI Product Management для Safari и компьютера.

После каждого отрезка появляется номер проверки: T-01…T-31. Проверки и обсуждение кейсов проходят в отдельном чате «тестирование». Полей ответов, оценок и копирования в читалке нет.

Место чтения и настройки сохраняются в браузере. При возвращении из другого приложения чтение остаётся на паузе. После первого открытия с интернетом и сохранения автономной версии учебник можно читать без сети. Статус доступен в меню «Разделы».

В этом репозитории нет ответов пользователя, исходных чатов, PDF-книг, банка вопросов или эталонов оценивания. Удаление данных сайта удаляет локальную позицию и настройки.
